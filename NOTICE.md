# Credits

`data/schema.json` and `data/object-names.txt` (and `src/schema-data.js` / `src/names-data.js`,
generated from them) come from **GD Info Explorer**: <https://flowvix.github.io/gd-info-explorer/>

- `schema.json` describes, for each kind of Geometry Dash object, which property keys exist, their
  names and types, and which object IDs belong to which class.
- `object-names.txt` is the Object IDs list: an ID followed by its name.

The site credits Alphalaneous and the community for naming the objects, and this project does the
same: thank you to Alphalaneous and the community.

The data is used as published on that site. If you find an error in it, the fix belongs upstream.
